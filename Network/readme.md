# Basic Cisco Packet Tracer Network

## Project Overview

This project demonstrates a basic inter-network connection created using Cisco Packet Tracer.

The topology contains:

- 1 × Cisco 1941 Router
- 2 × Cisco 2960 Switches
- Multiple PCs and a laptop
- Two separate IPv4 networks

## Network Addressing

### Network 1
- Network: `192.168.1.0/24`
- Router Gateway: `192.168.1.1`
- PC 1: `192.168.1.11`
- PC 2: `192.168.1.12`
- Laptop: `192.168.1.13`

### Network 2
- Network: `192.168.2.0/24`
- Router Gateway: `192.168.2.1`
- PC 1: `192.168.2.11`
- PC 2: `192.168.2.12`
- PC 3: `192.168.2.13`

## Devices Used

PCs/Laptop → Switches → Cisco 1941 Router → Other Network

## Objective

The objective of this project is to understand:

- Basic network topology
- IPv4 addressing
- Subnetting basics
- Switch-to-router connections
- Router interfaces
- Default gateways
- Communication between different networks
- Basic network troubleshooting

## Verification

Connectivity was tested using ICMP/Ping in Cisco Packet Tracer.

The simulation shows successful communication between devices.
